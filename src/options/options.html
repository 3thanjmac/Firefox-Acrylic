Windows backdrop (advanced)

Windows backdrop uses the real Windows 11 acrylic material behind the browser window instead of a simulated one. Firefox only exposes it through a few preferences and a userChrome.css rule, which extensions can't set for you:

  1. Open about:config and set:
    widget.windows.micatrue
    widget.windows.mica.toplevel-backdrop2 (acrylic)
    browser.tabs.allow_transparent_browsertrue
    toolkit.legacyUserProfileCustomizations.stylesheetstrue
  2. Open about:support → Profile Folder → Open Folder. Create a chrome folder there with a userChrome.css containing: 
    /* Let the window's acrylic backdrop show through the content area. */
:root {
  --tabpanel-background-color: transparent !important;
}
  3. Keep the default Firefox theme (Mica is disabled with other themes) and restart Firefox.
